# Articles

Guides for using Tharga.Crawler.

- **[Getting started](getting-started.md)** — install, namespace, a minimal crawl, events, and dependency injection.
- **[Configuration](configuration.md)** — `CrawlerOptions`, `DownloadOptions`, `SchedulerOptions`, the user-agent library, cancellation, and the shape of `CrawlerResult`.
- **[Custom services](custom-services.md)** — replace the built-in `IDownloader`, `IPageProcessor`, `IScheduler`, or `IUriService` to crawl with a headless browser, persist the queue, parse non-HTML, or apply custom URI filtering and rewriting.
